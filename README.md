# VESTE — Moda Consciente

Projeto desenvolvido para a disciplina de Desenvolvimento Web — Unidade 3: CSS e Design Responsivo.

##  Objetivo da Atividade

Adaptar uma página semântica já existente para um layout totalmente responsivo, garantindo boa experiência de uso em:

-  Celulares
-  Tablets
-  Desktops

A atividade teve como foco a aplicação de conceitos de:

- Design Responsivo
- Mobile-First
- Media Queries
- CSS Grid
- Layouts Fluídos
- Acessibilidade Semântica

---

#  Tecnologias Utilizadas

- HTML5
- CSS3
- CSS Grid
- Media Queries

---

#  Responsividade Implementada

O projeto foi desenvolvido seguindo a abordagem **Mobile-First**, começando pelas telas menores e expandindo para telas maiores.

## Breakpoints utilizados

### Mobile (padrão)
- Layout em 1 coluna
- Navegação adaptada
- Elementos empilhados

### Tablet (≥ 600px)
- Layout em 2 colunas
- Ajuste de tipografia
- Melhor aproveitamento de espaço

### Desktop (≥ 1024px)
- Layout em 3 colunas
- Hero section em duas colunas
- Footer expandido

---

#  Funcionalidades da Página

- Header semântico
- Navegação acessível
- Hero section responsiva
- Grid de produtos adaptável
- Banner informativo
- Footer organizado
- Layout fluído
- Imagens responsivas
- Sem rolagem horizontal

---

#  Acessibilidade

Foram utilizadas boas práticas de acessibilidade:

- Estrutura semântica (`header`, `main`, `section`, `footer`)
- Uso de `aria-label`
- Navegação organizada
- Conteúdo estruturado corretamente
